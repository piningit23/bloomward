BLOOMWARD — guard the last Glowbloom. You are the firefly Warden of a sunlit meadow: shoot pollen, dash, plant thorn traps, and hold the flower through 10 waves of blight — mites, beetles, spitters, splitters, blinking moths, siege brutes, dashing wasps, exploding spores, elites, and two bosses. Clear a wave to pick 1 of 3 bloom blessings from a pool of 15. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests — every asset is a file under `game/`.
